# 分鏡腳本 Storyboard V2

## 基本資訊

- 片名暫定：海海與粒粒
- 角色：海海（帝王企鵝）、粒粒（小藍企鵝）
- 總長度：約 2 分鐘
- 結構：三幕式喜劇短片
- 核心情緒：可愛、誇張、失控喜劇，最後轉為溫柔敬虔與婚禮收束

## 製作備註

- 第一幕要把「地下室秘密感」做出來，從教堂外觀快速轉入冰塊廚房。
- 第二幕以「便當消失」為主，粒粒的暴食節奏可以明顯更快、更誇張。
- 第三幕前半段保持失控喜劇，後半段要明顯切換成神聖、溫柔、和解的氛圍。
- 結尾的婚禮標語可以作為淡出收束，讓整體更像完整短片段落。
