# 分鏡腳本 Storyboard V2.1

## 基本資訊

- 片名暫定：海海與粒粒
- 角色：海海（帝王企鵝）、粒粒（小藍企鵝）
- 總長度：約 2 分 15 秒
- 版本：V2.1 細化鏡頭版

- 核心情緒：秘密甜蜜、誇張失控、恩典和好、婚禮銜接

## 製作備註

- V2.1 將原本的大段落拆成更細的鏡頭語言，適合後續製作 animatic。
- 第一幕的節奏重點是「甜蜜秘密被打斷」，快剪輯鏡頭 6-7 要有明顯喜劇速度感。
- 第二幕的重點是粒粒從萌到吸塵器模式的瞬間切換，鏡頭 12-13 要非常有節奏。
- 第三幕鏡頭最多，前半段要維持高速失控，鏡頭 32 之後要明顯切換為安靜、溫暖、神聖的和解氛圍。
- 結尾字幕「感謝上帝的帶領，讓我們互補同行。」是婚禮過場情緒收束。
