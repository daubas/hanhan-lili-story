# 分鏡圖生成 Brief

## 參考角色

- 海海：帝王企鵝，黑白身體、黃色臉頰與橘色嘴喙，戴厚實米色針織圍巾。體型大、可靠、笨拙、動作厚重。
- 粒粒：小藍企鵝，藍色羊毛氈身體、白色肚子、大黑眼、粉紅腮紅，抱著粉色愛心手機。體型約為海海的 1/4 到 1/5，活潑、可愛、反應快。

## 統一視覺風格

- 3D needle-felted wool plush characters.
- Soft toy texture, visible felt fibers, handmade miniature set.
- Snowy Antarctic ice field, pastel cinematic lighting.
- Cute slapstick comedy, exaggerated manga symbols, no realism gore.
- 分鏡稿格式：每個鏡頭有頭幀 Start Frame 與尾幀 End Frame。
- 構圖：乾淨、可讀、適合動畫前期 storyboard pitch。
