# Storyboard V3 - 15 秒固定 Section 製作腳本

## 我的理解

V3 的核心不是只把 V2.2 平均切成 15 秒，而是要改成「每段都能獨立製作、又能彼此接上」的製作腳本。

- 每個 section 固定 15 秒，方便逐段生成與管理。
- 全片目前維持 9 個 section，總長 2 分 15 秒。
- 每個 section 需要明確列出人物參考圖與場景參考圖。
- 每個 section 要標出 `Start Anchor` 和 `End Anchor`，讓製作知道片段開始和結束時角色、道具、背景要停在哪個狀態。
- 每個 section 之間最多允許 3 秒 overlap。這 3 秒不是增加總片長，而是製作用的銜接緩衝：上一段最後 3 秒和下一段前 3 秒要共享同一個動作狀態、構圖或場景狀態，方便剪輯時對齊。
- 場景參考圖要先固定，常用場景不能每段重新長一套。尤其地下室廚房、冰雕餐具店、滑行路線、軟雪牆、和解雪地都需要固定參考圖。

## Overlap 規則

| 項目 | 規格 |
| --- | --- |
| Section 長度 | 每段固定 15 秒 |
| Overlap 長度 | 每個銜接最多 3 秒 |
| Overlap 用途 | 上一段 End Anchor 與下一段 Start Anchor 共用同一個狀態 |
| 剪輯方式 | 可直接剪接、交叉淡入淡出，或用同一動作點對齊 |
| 禁止事項 | 不要讓下一段開頭突然換背景、換角色站位或重置道具 |

## 生圖規格

每個 V3 section 生圖或產影片時，prompt 至少要包含：

- 角色參考：海海與粒粒的 charsheet 路徑。
- 場景參考：本 section 表格列出的 SC 場景圖。
- Start Anchor：開頭 0-3 秒必須承接上一段。
- End Anchor：結尾最後 0-3 秒必須能接下一段。
- Overlap 長度：最多 3 秒。
- 角色比例：粒粒高度固定為海海的 1/4 到 1/5。
- 文字限制：影片畫面內不放字幕、可讀文字或字卡。

## 優先補圖順序

1. 先補 `assets/scene-references/` 下的 SC-03、SC-05、SC-07、SC-09，因為它們影響最多 section。
2. 再補 SC-01、SC-04、SC-06、SC-08。
3. 最後補 SC-02，因為它只服務開場轉場。
